# AtlasAuth static site

A dependency-free, working static landing site for an auth/licensing platform concept.

## Run locally

```bash
cd atlasauth-site
python -m http.server 4173
```

Open http://127.0.0.1:4173.

## Working interactions

- Mobile navigation toggle
- Demo account modal with local browser storage
- License verifier simulator
- Demo key generator
- Monthly/annual pricing toggle
- Code snippet copy button
- Animated dashboard counters
